Netxus User Stories:

User Posts:
As a User, I should be able to find discussions about a media, So that I can read what others think about it.

As a User, I should be able to create a post under a discussion, So that I can engage in said discussion on my media.

As a User, I should be able to subscribe to a discussion, So that I can be aware of new topics.

As a User, I should be able to create a new discussion for a media if one does not exist already, so that I can start a discourse on said media.

As a User, I should be able to delete posts that I create, So that I can manage my content.

As a user, I should be able to like and dislike posts, So that I can give my opinion.

As a user, I should be able to report posts or users, So that I can make the site a better place.


User Account:
As a User, I should be able to create an account, So that I can store and quickly access my favorite posts and discussions.

As a User, I should be able to delete my account, So that I can remove myself from the app.

As a User, I should be able to update/manage my account settings, So that I can change any relative information regarding my account.


Moderator/Admin:
As an Admin, I should be able to delete any user's posts, So that I can enforce site rules.

As an Admin, I should be able to delete a discussion, So that I can enforce site rules.

As an Admin, I should be able give warnings to users who violate rules, So that I can enforce site rules.

As an Admin, I should be able to ban and delete accounts, So that I can enforce site rules.

As an Admin, I should have the same features as a regular user, So That I can test and use the site.
